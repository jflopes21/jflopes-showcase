## 🚀 Sobre o Projeto

Este é o portfólio profissional de **João Francisco P. Lopes** (JFLopes), desenvolvido para apresentar minhas habilidades em desenvolvimento Full Stack, focando em performance, experiência do usuário (UX/UI) e modernidade.

O projeto foi construído utilizando as tecnologias mais atuais do ecossistema React/Next.js.

### ✨ Destaques Técnicos (Golaços do Projeto)

- **Next.js App Router:** Utilização completa do novo sistema de rotas para Server Components e Client Components, garantindo SEO e alta performance.
- **Internacionalização (i18n):** Suporte nativo a múltiplos idiomas (`pt-br`, `en`, `es`, `de`, `fr`, `pt-pt`) com roteamento baseado em `locale` (`/en/`, `/pt-br/`), usando a biblioteca `next-intl`.
- **Performance:** Uso de Server Components para renderização estática e otimização de assets (imagens, fontes, etc.).
- **Animações:** Efeitos de scroll e entrada de elementos leves e dinâmicos através da biblioteca **Framer Motion**.
- **Acessibilidade (A11y):** Componentes baseados em primitivas Radix UI (Shadcn/UI), com foco em semântica e padrões WAI-ARIA.

## 💻 Como Rodar o Projeto (Passo a Passo)

Siga os passos para ter o projeto rodando em sua máquina local.

### Pré-requisitos

Certifique-se de ter instalado:

- [Node.js](https://nodejs.org/en/) (v18+)
- npm ou Yarn (Recomendado: npm)

### Instalação

1.  Clone o repositório:

    ```bash
    git clone [URL_DO_SEU_REPOSITORIO]
    cd jflopes-showcase
    ```

2.  Instale as dependências:
    ```bash
    npm install
    # ou yarn install
    ```

### Execução

1.  Inicie o servidor de desenvolvimento:

    ```bash
    npm run dev
    # ou yarn dev
    ```

2.  Acesse o portfólio no navegador:
    O projeto estará rodando em: `http://localhost:3000/pt-br`
